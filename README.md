# Claude API 最低充值金额：5 美元起，国内用户先解决怎么付，再决定充多少不浪费

先给数字。Anthropic 的 Claude API 用的是预付费额度（prepaid credits），Console 里最低一档是 **$5**。不是试用价，也不是首充优惠，就是最小购买单位。

但把"最低充值金额"当成唯一答案，后面基本都会再回来补一次课。因为 $5 只是门槛，它不告诉你这笔钱能用多久、会不会过期、国内卡刷不过该怎么办。下面按这几个真问题拆。

## $5 是门槛，不是"建议金额"

官方 Billing 页面上的固定选项是 $5、$20、$100，以及一个自定义金额入口。$20 被标为推荐值——这是页面默认选中项，跟你的实际用量没关系。

多位开发者的购买记录写得很一致：**最低购买额度 5 美元，必须用信用卡支付**。这个数字在不同来源里反复出现，包括 Claude 文档里 Tier 1 的"$5 deposit / $100 monthly usage"示例。如果你在别的文章里看到"1 美元起"，那通常是在说第三方中转网关，不是 Anthropic 官方额度，两者不能混算。

顺便说一个容易被忽略的细节：$5 是额度金额，不是账单总额。有开发者记录显示，购买 $20 额度时结算总额是 $22.00——多出来的部分是当地税费。你的实际支出取决于账单地址所在地区。

## 为什么 $40 比 $5 更值得记住

这一条比最低充值金额更重要。

Anthropic 的 usage tier 是**按累计购买金额**升级的，不是按月消费：

| 目标 | 触发条件 | 对应月度用量上限 |
| --- | --- | --- |
| Tier 1 | 首次购买 $5 | $100 / 月 |
| Tier 2 | 累计购买满 $40 | $500 / 月 |
| Tier 3 | 累计购买满 $200 | $1,000 / 月 |
| 更高档位 | 按 tier 逐级放开 | 上限区间约 $500 – $200,000 / 月 |

也就是说，$5 和 $40 不是"多充少充"的区别，而是两个不同的使用阶段。你充 $5，账户每月能承接 $100 的调用量；累计买到 $40，月度空间直接跳到 $500。如果你只是验证原型，$5 完全够；如果你接下来两周要跑高频测试或者多人联调，一次性把累计购买做到 $40 更省事——省的不是单价，是反复撞月度上限的时间。

## 充值规则里有五条要提前知道

**额度一年过期，而且不能延长。** 所有充值额度从购买日起一年内有效，到期作废，官方明确写了不可延期、不可退款。这一条直接推翻"充多点反正不亏"的想法——如果你一年用不掉，多充就是纯粹的资金占用。

**余额挂在组织上，不属于单个 API key。** 组织下的多个 key 共用同一笔余额。如果你习惯给每个项目单独发 key 分别记账，这在 Anthropic 上做不到，得自己在应用层做计量。

**失败请求不收费，但"正在跑然后超时"的请求照扣。** 前者是净赚，后者是你为一次没拿到结果的调用付了钱。做批量任务时这点比看起来重要。

**Claude Pro / Max 会员不含 API 额度。** 两套系统，各付各的。买了 Pro 还是要单独充值才能调 API，这条经常被搞混。

**新账号的赠送额度别写进预算。** 有些博客提到"新账号送 $5"，但官方页面没有这个承诺。指望它来省下最低充值金额，落地时大概率落空。

## 充 $5 到底能跑多少次请求

按公开的 Sonnet 级单价估算，一次 2,000 输入 token + 500 输出 token 的测试请求，成本约 0.009 美元——不到 1 美分。$5 差不多能跑五百多次这种规模的调用。

真正影响这笔钱寿命的是你选哪个模型。同一代里，Opus 档的输入输出单价通常是 Sonnet 档的数倍，同样的 $5 在高档模型上很快就见底。所以"最低充值金额"这个问题，实际要配合"我打算用哪个模型"一起回答。

## 国内用户卡住的不是金额，是付款方式

官方购买额度必须用信用卡。国内银行发的 Visa / Mastercard 外币卡在这一步经常被拒，原因不在余额，而在发卡地区、账单地址和风控综合判断。这才是"Claude API 最低充值金额"被反复搜索的真实原因——$5 谁都出得起，只是付不出去。

现在可行的路子大概三条：

**官方直充。** 有可用境外卡的话，这是手续费最低、最干净的选择。社区里的经验是 Claude 的卡风控比 OpenAI 松，普通虚拟卡加一个美国免税州账单地址通常能过。代价是你得自己搞定卡和地址。

**第三方代付。** 用支付宝或微信付款，平台收一定手续费，最终价格高于官方原价。BeWild（也就是 WildAI，前身是 WildCard／野卡）就是这个路线里国内知名度较高的一个，它做的是订阅代付，同时也在承接开发者的额度和 API 相关充值需求——社区里对它的评价是"就是加点手续费"。这条线具体支持哪些额度、当前最低多少，以下单页面显示为准，别拿别人几年前的截图当价格。

**云平台后付费。** 通过 AWS Bedrock 或 Microsoft Foundry 调用 Claude，走的是月结账单，不需要提前充值，也就没有最低金额这个限制。已经有云账号和云额度的团队可以优先看这条，缺点是接入方式和第一方 API 不完全一样，部分功能可能受限。

另外还有一类第三方网关，把最低充值压到 $1 甚至 $0.5。价格门槛确实低，但那是走别人的中转通道，配额、合规、稳定性和账号归属都跟官方额度不是一回事，用来省下 $5 并不划算。
